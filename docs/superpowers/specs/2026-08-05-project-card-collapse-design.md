# 项目卡单项折叠设计

## 目标

让用户可以分别收起或展开活动项目，减少项目列表的纵向占用；折叠偏好保存在本机，重新进入页面后仍生效。

## 交互

- 每个活动项目标题行新增独立的折叠箭头入口，点击区不少于 `56rpx`。
- 项目默认展开；新建项目默认展开。
- 展开时保持现有信息层级：标题、截止时间、未完成子任务、已完成子任务入口和添加子任务入口。
- 折叠时只保留标题行、折叠箭头和“…”管理入口；截止时间及所有子任务相关内容均隐藏。
- “…”管理入口与折叠入口互不影响；不把项目标题设为折叠入口。

## 状态与存储

- 页面以项目 `id` 集合表示已折叠的活动项目。
- 该集合存入独立的本机 `wx` 存储键，读取失败、格式不合法或不存在时安全降级为全部展开。
- 此状态不写入 `Project`、不参与 JSON 导入导出、统计或跨设备同步；归档和放弃项目时移除对应本机状态。

## 边界

- 不改变项目、任务、日历、计时器或统计的领域语义。
- 保留当前项目内未完成/已完成子任务的独立展开状态；项目重新展开后按原有页面状态展示。
- 不新增回归断言，按当前确认仅做现有测试与模拟器验证。

## 验收

1. 多个项目可独立折叠与展开。
2. 刷新或重新进入计划页后，已折叠项目仍保持折叠。
3. 折叠项目不显示截止时间、子任务和添加入口，但仍可通过“…”管理。
4. 默认展开和新建项目默认展开。
