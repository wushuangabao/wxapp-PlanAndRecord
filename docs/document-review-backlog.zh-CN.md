## 代码与产品一致性待复核

以下事项均为审查发现，状态为“待产品/实现复核”。记录这些事项不表示已经修改产品基线，也不表示已经选定修复方案。

| 优先级 | 议题 | 现状与待复核事项 |
| --- | --- | --- |
| P2 | 历史日志编辑与归档分类 | 当前日志编辑入口只提供日期、时间和备注，未覆盖产品基线允许修改的分类、项目、任务、计划块和标签；同时，历史日志原分类归档后，更新流程会重新校验该分类并阻断编辑。需复核交互字段是否补齐，以及历史日志保留归档分类引用时的编辑校验方式。 |
| P2 | 清空数据与导出临时文件 | 当前产品导出临时文件的读取或删除失败可能只记录警告，资料库清空后仍提示“数据已清空”。需按产品基线 5.4.3 复核文件清理失败、资料库原子写入和成功提示之间的边界，避免临时文件残留时误报完整清空。 |
| P2 | 重复实例“此项及后续”的标题 | 编辑弹层允许输入标题，但提交“此项及后续”修订时未传递标题，用户输入不会生效。需复核标题是否属于规则修订字段；若属于，应补齐实现与回归测试，若不属于，应同步收敛交互并确认产品定义。 |
| P2 | 过夜重复候选跨统计范围起点 | 虚拟候选当前按实例开始时间投影；若实例在查询范围开始前启动、结束后落入范围（例如 23:30–00:30 查询次日），会被漏计，而持久化日志采用时间区间相交口径。需复核虚拟候选是否也统一采用区间相交口径，并补充跨日、跨周/月边界回归。 |

| 优先级 | 议题 | 待确认的决策 |

| 高 | `pageId` 与页面关联 | 监听回调得到 `pageId`，但示例页面通过未说明来源的 `this.getPageId()` 获取它。应采用官方支持的关联方式，或在 query 中传递并校验一次性关联 ID。 |
