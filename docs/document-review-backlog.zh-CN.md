## 小微 AI Handoff 规范待复核

| 优先级 | 议题 | 待确认的决策 |
| --- | --- | --- |
| 高 | `pageId` 与页面关联 | 监听回调得到 `pageId`，但示例页面通过未说明来源的 `this.getPageId()` 获取它。应采用官方支持的关联方式，或在 query 中传递并校验一次性关联 ID。 |
| 高 | 平台兼容性 | 需要明确“小程序 AI 编译”、`wx.modelContext`、`wx.onAgentHandoff` 的最低基础库、开发者工具版本及兼容性测试矩阵。 |
| 中 | 配置示例完整性 | 示例引用 `page-meta.json`，目录树未列出该文件，也未给出路径、Schema 和多个 Skill 的合并规则；直接复制数组配置可能覆盖既有配置。 |
| 中 | 组件声明 | 当前要求每个接口声明 `componentPath`，但 Handoff 不渲染原子组件。是否应改为仅在确有可复用组件时声明？ |
| 中 | payload 生命周期 | 除“非敏感”外，尚未规定允许字段、大小、Schema、过期时间、缓存上限和页面路径校验。 |
| 中 | 接口演进 | `inputSchema`、`outputSchema` 与错误结果没有版本和兼容策略；多端升级时如何识别不兼容变更？ |
| 低 | 仓库领域示例 | 规范主要使用订单、地址、支付示例。是否补充本项目的导入草稿、候选日志确认和匿名本地资料库示例？ |
